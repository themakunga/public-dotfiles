# Sofle configuration moved

The Sofle RGB keyboard `eva01` and keymap `nicolas` is maintained in
[themakunga/keyboards](https://github.com/themakunga/keyboards/tree/main/keyboards/themakunga/eva01/keymaps/nicolas).

The dedicated repository contains the keymap, OLED/Bongo Cat sources, licenses, hardware notes and
checks. Use its external QMK userspace instructions to build `themakunga/eva01:nicolas`.
