# Sofle configuration moved

The Sofle RGB EVA-01 keymap `nicolas` is maintained in
[themakunga/keyboards](https://github.com/themakunga/keyboards/tree/main/keyboards/sofle/keymaps/nicolas).

The dedicated repository contains the keymap, OLED/Bongo Cat sources, licenses, hardware notes and
checks. Use its external QMK userspace instructions to build `sofle/rev1:nicolas`.
