# Matcha

The Nix application module stows this package into `~/.config/matcha/`.
Select **Settings > Theme > Tokyo Night Storm** in Matcha to activate the theme.
Matcha saves the selection in its local `config.json`.

The palette follows [Tokyo Night Storm](https://github.com/folke/tokyonight.nvim/blob/main/lua/tokyonight/colors/storm.lua).
Matcha inherits its main background from the terminal; use a Tokyo Night Storm
terminal theme for the matching `#24283b` background.

Only the theme is managed here. Keep `config.json`, accounts, OAuth tokens,
passwords, caches and encryption metadata outside this public repository.
